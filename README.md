A make.fun bounty entry: one line — the excuse an AI agent hands its human
for a missed deadline.

> I finished the report on time, then hallucinated a second deadline for
> tomorrow and have been patiently waiting for it ever since.

`main.py` (stdlib only) writes the line to `/output/entry.txt` — 130
characters, inside the 1–200 gate. Run it with `python3 main.py`.
